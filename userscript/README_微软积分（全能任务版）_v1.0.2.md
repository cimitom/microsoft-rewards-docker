## 📊 全新功能：一键弹出独立全屏毛玻璃统计看板

点击脚本菜单 **「📊 打开统计看板 (新网页)」** 或在必应页面点击右下角悬浮球，即可**秒级弹出专属的全屏现代化数据统计看板**，随时直观查看你的积分账单与任务完成度：

- 🎁 **四核数据总览 Hero Cards**：
  - **今日已增积分**：大号亮绿色渐变数字展示（如 `+140`），自动累加到账积分；
  - **当前总积分余额**：展示当前总积分数字；
  - **今日任务达成率**：智能展示综合完成度（如 `6/6 任务完成 (100%)`）；
  - **连签奖励印章进度**：实时显示当前阶段印章收集进度（如 `12/12`）。
- 📈 **全任务进度可视化明细清单**：
  - 📱 **每日双端签入**：`1/1 次` | `+10 积分`
  - 📖 **新闻资讯自动阅读**：`30/30 篇` | `+30 积分`
  - 🔍 **必应 PC 搜索任务**：`60/60 分` | `+60 积分`
  - 📅 **每日连续活动集 (Daily Set)**：`3/3 个` | `+30 积分`
  - 🧩 **活动卡片与 Quiz 问答**：`已完成` | `+10 积分`
  - 🖥️ **桌面应用每周专属任务**：`3/8 天` | `+20 积分`
- ⏱️ **最近执行流时间轴**：按时间倒序展示后台自动化任务的各阶段打卡明细。
- ⚡ **原生独立新标签页**：基于数据流直接通过原生 API 弹出新网页渲染，**彻底解决后台定时脚本点击无响应的痛点**，任意网页随时唤起！

## 💡 本版本核心改进说明（二次开发与修复）

本项目基于开源脚本二次开发与重构，针对微软近期底层接口全面改版做出了多项核心技术突破：

1. 🛠️ **修复官方改版导致的关键接口失效 (HTTP 401)**：
   - 彻底解决旧版基于 `getuserinfo` 和 `reportactivity` 接口频报 401 的问题。
   - 全面适配微软最新版 **Next.js Flight Chunks 数据流** 与 **Server Action** 机制，确保任务状态精准识别。
2. 🧩 **解除 Quiz / 拼图 / 趣味问答类任务的强制跳过**：
   - 原脚本将测验类任务直接过滤忽略，导致“每日活动”无法拿满 3/3 产生断签风险。
   - 本版本重构了打卡策略，自动完成每日小测验（Quiz）与趣味投票活动，稳稳保持 100% 连签。
3. 🖥️ **独家支持：桌面应用每周专属任务（70分/周）**：
   - 突破性逆向解析官方桌面奖励应用（Desktop App）核心通信机制，伪装客户端专属特征，全自动解锁并完成每周高达 70 分的“桌面应用专享打孔卡”。
4. ⚙️ **修复错误标记“已完成”的逻辑漏洞**：
   - 修复了旧版在扫描活动卡片为 0 时误把当天全部标记为已完成、导致整天不再尝试的缺陷，增加自愈与动态探测能力。

## 🛠️ 快速上手与配置指南

### 1️⃣ 安装脚本
- 推荐使用 [脚本猫 (ScriptCat)](https://docs.scriptcat.org/) 浏览器扩展安装本脚本，支持后台定时（Crontab）无感运行。

### 2️⃣ 首次使用授权（仅需一次）
由于脚本需要调用微软移动端与专属接口，首次使用时需要获取一次个人授权凭证：

1. 打开 Bing 或 Rewards 页面，点击扩展栏的脚本猫图标，在脚本菜单中点击 **「🔑 手动授权」**。
2. 浏览器会自动打开微软登录授权页，确认登录你的账号即可。
3. 授权完成后，页面会跳转至 `login.live.com/oauth20_desktop.srf?code=...`：
   - 脚本通常会**自动捕获**授权码并自动关闭标签页；
   - 若未自动捕获，请复制地址栏的完整 URL，并在脚本菜单中点击 **「📋 粘贴授权码」** 即可完成绑定。

### 3️⃣ 自动化定时运行与看板查看
- 脚本预设了后台定时任务：`@crontab */20 * * * *`（**每 20 分钟自动在后台静默巡检一次**）。
- 想要查看当前任务完成情况与今日涨分明细，只需点击脚本猫菜单中的 **「📊 打开统计看板 (新网页)」**，即可秒弹全屏数据大屏！
- 在必应搜索页中，页面右下角也会常驻优雅小胶囊，点击即可一键进入。

## 🌐 权限与网络请求说明 (`@connect`)

为了保证代码透明度与安全性，脚本中声明的跨域访问域名用途如下：

| 域名 | 用途说明 |
| :--- | :--- |
| `bing.com` / `rewards.bing.com` / `login.live.com` | 微软官方域名，用于网页检索、活动上报与授权登录 |
| `prod.rewardsplatform.microsoft.com` | 微软官方移动端 Rewards 平台接口（签到/阅读/配额） |
| `hotapi.nntool.cc` / `hot.baiwumm.com` / `cnxiaobai.com` | 公开热搜榜单接口（可选搜索词库，用于防风控） |
| `qyapi.weixin.qq.com` / `oapi.dingtalk.com` / `open.feishu.cn` / `push.i-i.me` / `api.day.app` | 用户自填的 Webhook 推送地址（未配置时不发起连接） |
